# Django Blog Website

A full-featured blog website built with Django.

## Features

- User Registration
- User Login
- User Logout
- Create Blog Posts
- Edit Own Posts
- Delete Own Posts
- Blog Post Details
- Comment System
- Like / Unlike Posts
- User Dashboard
- Django Admin Panel
- Responsive Bootstrap UI

## Technologies

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
